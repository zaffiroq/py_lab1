# toolkit — калькулятор и конвертер величин

Консольный Python-пакет с двумя утилитами: калькулятором арифметических выражений
и конвертером величин (длина, масса, температура). Работает из командной строки
через `python -m toolkit`.

## Установка

```
pip install -e .
```

## Помощь

```
python -m toolkit --help 
```

## Команда `calc` — калькулятор

```
python -m toolkit calc "EXPRESSION" 
```

Поддерживаются:

- целые и вещественные числа;
- операторы `+ - * /`;
- унарные плюс и минус перед числом;
- произвольные пробелы между токенами;
- приоритет: умножение и деление выполняются раньше сложения и вычитания;
- операции одного приоритета — слева направо;

## Команда `convert` — конвертер величин

```
python -m toolkit convert VALUE --from UNIT --to UNIT
```

Поддерживаемые группы:

| Группа | Единицы |
|---|---|
| Длина | `mm`, `cm`, `m`, `km` |
| Масса | `g`, `kg` |
| Температура | `c`, `f`, `k` |

Правила:

- регистр единиц не учитывается: `--from CM` и `--from cm` эквивалентны;
- конвертация между разными группами запрещена (нельзя, например, метры в граммы);
- температура ниже абсолютного нуля (−273.15 °C = 0 К) не допускается;
- результат возвращается как число с плавающей точкой;
